Industry website templates with a live, brandable customiser, real responsive device previews and a "Start My Project" enquiry flow.

== Description ==

* Creates a **Templates** page (`/templates/`) showing industry categories.
* **Dental Clinics** has a complete, working website template; other industries show as "Coming soon".
* Visitors personalise the template (name, contact details, hours, logo, colours, content) and see it update live.
* Mobile (390px), tablet (768px), laptop (1366px) and desktop (1440px) previews render the real responsive page in an iframe.
* "Start My Project" stores a private enquiry (admins only) with the selected template, personalisation and logo, and emails the site admin.

== Installation ==

1. Copy `deskman-templates` into `wp-content/plugins/` and activate it.
2. Activation creates the Templates page and adds it to the theme's primary menu (classic themes). On block themes, add the page in Appearance → Editor → Navigation if your navigation does not list pages automatically.
3. Enquiries appear under **Template Enquiries** in the admin menu.
